# Contexto — Refrizer

## Resumen
Sitio web de Refrizer: venta, instalación y mantención en refrigeración y electricidad para hogar y negocio.
Sitio en vivo: https://refrizer-web.vercel.app/

## Objetivo del sitio
Presentar productos y servicios de refrigeración y electricidad y facilitar el contacto.

## Público
Hogares y negocios de Santiago que compran, instalan o mantienen equipos de refrigeración y electricidad.

## Secciones
- Inicio
- Productos
- Servicios de instalación y mantención
- Contacto

## Contenido y datos
- Los textos, precios, teléfonos y certificaciones los entrega el cliente. La IA no inventa información del negocio: si falta un dato, se deja marcado como "por confirmar".
- Los productos son datos de ejemplo (src/mocks) hasta que el cliente entregue el catálogo real.

## Restricciones
- Este repositorio contiene solo el frontend (sin backend propio).
- No se suben secretos ni datos personales. Las variables de entorno van en .env (no versionado) y solo se usan variables públicas VITE_*.
- El dominio y el despliegue los gestiona una persona, no la IA.
